# Elina

## 简介

Minecraft 工具集，仍然基本不影响原版游戏内容。

[MCUCST](https://x.com/mcucst)自用，欢迎改进。

**警告**：早期功能尚不完整，不保证后续兼容性

## 组件

### *locate*

定位结构，但允许标记去过的结构

### *map*

包装的BlueMap API，若无BlueMap则什么都不做。

### *subway*

地铁绘制，标记线路和站点，然后自动在地图上连线！

### *farm*

快速查询物品刷新地点。

如果可能，可以使用findadv自动生成一条合成路径，需要先build。
